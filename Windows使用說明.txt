影片校色工具 0.1.1 — Windows 版

適用：Windows 10／11，64 位元 x64 電腦。

開啟
1. 把 ZIP 完整解壓縮，不要直接在壓縮檔內執行。
2. 開啟解壓縮資料夾內的 VideoColorFix.exe。
3. exe、DLL 和 resources 資料夾要放在一起，不能只搬走 exe。
4. 如果 Windows 顯示未識別的應用程式，確認檔案來源後，
   可按「其他資訊」或「更多資訊」，再按「仍要執行」。
   這是尚未購買程式簽章憑證的測試版，不需要系統管理員權限。

使用
1. 按「選擇影片」，或把影片拖進程式。
2. 預設固定使用剛才試修的校色設定：
   標準去黃、去黃強度 100%、色調 0、亮度 0，並保護亮部。
3. 左邊看原始畫面，右邊看校色結果。時間軸可切換預覽位置。
4. 按「另存校色影片」，另存為 MP4。
5. 不會覆蓋原始影片。可取消匯出；AAC／MP3 音訊直接保留，其他音訊轉為 AAC。

影片只在本機處理，不會上傳。不用安裝 Python、Node.js 或 FFmpeg。
本版支援一般 SDR 影片；HDR／BT.2020 影片及 Sony S-Log 應先在 Catalyst 正確轉成 Rec.709。
不是自動還原相機設定的工具。不同場景可以自行調整去黃強度。
